# Lessons

- Не рисовать поведение в макете по догадке. В макете Join показывался во время блока, хотя ссылка есть только у встречи. Сверять с кодом (`SnapshotBuilder.swift:133`) до макета.
- Цвет прошедшего слота выбирает пользователь. «Приглушить» не значит «сильно». Для прошлого: пастель, не бледный и не кричащий.
- Уточнять термины пользователя: Join — кнопка присоединиться ко встрече, «чёлка» и «шторка под камерой» — вырез камеры.
- Коммитить после зелёных тестов. Раз закоммитил до исправления тестов и пришлось делать `--amend`.
- `sed -i` на macOS требует `''`. Для правок файлов использовать python.
- Встроенный `isolation: "worktree"` у агентов делает worktree репозитория сессии (волт), не форка. Worktree форка создавать вручную.
- После каждого опубликованного артефакта перечитывать, что реально опубликовано, если правка шла через sed.
